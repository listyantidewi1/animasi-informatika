Bab sepuluh, berjalan tanpa internet. Di akhir bab ini, SiBaca berjalan dari satu laptop, dan bisa dibuka dari HP mana pun yang tersambung ke WiFi yang sama, tanpa internet.

Selama ini kita menjalankan dua program, yaitu Express dan Vite. Vite hanya alat bantu selama mengembangkan. Untuk dipakai sungguhan, kita meminta Vite mengemas seluruh kode React menjadi beberapa berkas biasa. Hentikan Vite, lalu di folder web, ketik npm run build. Hasilnya ada di folder dist. Lihat isinya. Ada satu berkas HTML, satu JavaScript, satu CSS, dan berkas-berkas huruf Inter. Semuanya ada di laptop ini, dan tidak ada satu pun yang diambil dari internet.

Sekarang kita meminta Express menyajikan folder itu. Di app titik js, baris express titik static berarti setiap berkas di folder dist bisa diminta oleh browser. Baris di bawahnya menangani alamat lain, misalnya garis miring pinjaman. Alamat seperti itu diatur oleh React, jadi server cukup mengirim index titik html, dan React yang menentukan halaman mana yang tampil. Di atasnya, kita menambah satu baris, supaya alamat API yang salah ketik dijawab dengan pesan yang jelas. Folder dist tidak ikut ke GitHub, karena Vite sudah mencantumkannya di titik gitignore miliknya, dan isinya bisa dibuat ulang kapan saja.

Tambahkan perintah start di package titik json, yaitu perintah dev tanpa pilihan watch. Hentikan server yang lama, jalankan npm start, lalu buka localhost titik dua tiga ribu. Perhatikan, kali ini port tiga ribu, bukan lima satu tujuh tiga. Satu program sekarang melayani tampilan sekaligus datanya.

Sekarang dari HP. Laptop dan HP harus tersambung ke WiFi yang sama. Kita perlu tahu alamat laptop di jaringan itu. Di Windows, ketik ipconfig, lalu cari baris IPv4 Address. Di contoh ini, alamatnya satu sembilan dua, titik satu enam delapan, titik satu, titik sepuluh. Di browser HP, ketik alamat itu, diikuti titik dua tiga ribu.

Kalau halamannya tidak mau terbuka, hampir selalu penyebabnya firewall. Saat server pertama kali dijalankan, Windows bertanya apakah Node.js boleh diakses dari jaringan. Centang Private networks, lalu tekan Allow. Kalau jendela itu sudah telanjur ditutup, cara membukanya lagi ada di README. Satu hal lagi. Alamat laptop bisa berubah setiap kali router dinyalakan ulang. Supaya tetap, buka pengaturan router, cari menu address reservation, lalu kunci alamat untuk laptop Bu Ratih.

Sekarang pembuktiannya. Kabel internet di router kita cabut. Di HP, Nadia membuka alamat laptop, login, mencari buku, lalu meminjam. Semuanya berjalan, dengan huruf dan tampilan yang utuh. Kenapa bisa? Karena dua keputusan kecil di bab enam. Huruf Inter kita simpan di dalam proyek, dan alamat API kita tulis relatif, tanpa nama komputer. Jadi, apa pun alamat yang dipakai untuk membuka halaman, ke alamat itulah permintaan datanya dikirim.

Cek kerjaan AI. Ini potongan dari aplikasi buatan AI yang gagal di awal video. Ada tiga baris yang membuatnya tidak bisa dipakai di perpustakaan Bu Ratih. Yang mana, dan kenapa? Pikirkan dulu.

Dua baris pertama mengambil huruf dan gaya tampilan dari internet. Di rumah, itu berhasil. Di perpustakaan tanpa internet, browser menunggu lama, lalu menampilkan halaman tanpa gaya. Baris ketiga adalah alamat API yang berisi localhost. Di laptop, localhost berarti laptop itu sendiri, jadi berhasil. Di HP Nadia, localhost berarti HP Nadia, dan di sana tidak ada server apa pun. AI tidak salah menulis kode. Ia hanya tidak tahu bahwa perpustakaannya tanpa internet, karena tidak ada yang memberitahunya. Commit dengan pesan, berjalan tanpa internet. Sekarang seluruh perpustakaan bergantung pada satu laptop. Lalu, bagaimana kalau besok laptop itu rusak? Itu kita jawab di bab terakhir.
