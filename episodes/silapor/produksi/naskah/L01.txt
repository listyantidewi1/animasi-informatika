Bab satu, persiapan. Di akhir bab ini, Laravel sudah berjalan di komputermu dan tersambung ke database MySQL. Aku menganggap komputermu masih kosong, jadi kita pasang semuanya satu per satu. Kalau PHP, Composer, MySQL, VS Code, dan Git sudah terpasang, silakan lompat ke bagian membuat proyek lewat cap waktu di deskripsi.

Alat pertama adalah Laravel Herd. Laravel butuh PHP, Composer untuk memasang pustaka PHP, dan Node.js. Herd memasang ketiganya sekaligus, dan versi dasarnya gratis. Buka herd titik laravel titik com, unduh versi untuk Windows atau Mac, lalu jalankan penginstalnya. Di Windows, klik Yes saat diminta izin, lalu tunggu sampai selesai. Setelah itu, buka Herd satu kali supaya ia menyiapkan PHP. Untuk Linux, perintah pemasangannya ada di README, di alamat GitHub yang tampil di layar ini.

Alat kedua adalah MySQL, database kita. Buka dev titik mysql titik com garis miring downloads, lalu pilih MySQL Installer untuk Windows. Di halaman pertama penginstal, pilih Server only, karena kita hanya butuh servernya. Tekan Next sampai tiba di halaman Accounts and Roles. Di sini kamu membuat kata sandi untuk pengguna bernama root. Catat baik-baik kata sandi ini, karena root adalah pemilik seluruh database di komputermu. Halaman lainnya biarkan seperti bawaannya, lalu tekan Execute dan Finish.

Alat ketiga adalah Git, untuk menyimpan riwayat kode. Unduh dari git-scm.com, lalu pasang dengan pilihan bawaannya. Di Windows, Git membawa terminal bernama Git Bash. Alat keempat adalah VS Code, dari code.visualstudio.com. Setelah terpasang, buka panel terminal lewat menu Terminal, New Terminal. Klik panah kecil di samping tanda tambah, lalu pilih Git Bash. Pakailah terminal ini, supaya perintah yang kamu ketik sama persis dengan yang kuketik.

Sekarang kita periksa. Ketik php minus minus version, lalu composer minus minus version, lalu mysql minus minus version, dan terakhir git minus minus version. Kalau keempatnya menjawab dengan nomor versi, semua alat sudah siap. Kalau ada yang menjawab command not found, tutup VS Code, buka lagi, lalu coba sekali lagi. Kalau mysql masih tidak dikenali, artinya Windows belum tahu letak programnya, dan cara mengatasinya ada di README.

Sekarang kita membuat proyeknya. Buka terminal, lalu ketik laravel new silapor, diikuti tiga pilihan. Pilihan minus minus database sama dengan mysql berarti kita memakai MySQL. Pilihan minus minus phpunit memilih alat test bawaan. Pilihan minus minus no boost melewati alat tambahan yang belum kita perlukan. Penginstal lalu bertanya dua hal. Untuk starter kit, jawab No, karena kita ingin menulis halaman login sendiri supaya paham isinya. Untuk frontend, pilih Blade, yaitu cara Laravel menulis halaman HTML. Laravel lalu mengunduh semua pustakanya, dan ini bisa memakan beberapa menit. Kalau muncul tanda silang di baris Database migrated, itu wajar, karena database-nya memang belum kita buat.

Buka folder silapor di VS Code, lewat menu File, Open Folder. Inilah isi proyek Laravel. Kamu tidak perlu hafal semuanya sekarang. Cukup kenali empat tempat. Folder app berisi logika aplikasi. Folder routes berisi daftar alamat. Folder resources garis miring views berisi halaman. Folder database berisi rancangan tabel. Sisanya kita kenali sambil jalan.

Berikutnya, database. Kita masuk ke MySQL sebagai root dengan perintah mysql minus u root minus p, lalu ketik kata sandi root tadi. Saat diketik, kata sandi memang tidak terlihat. Kita membuat database bernama silapor. Lalu kita membuat pengguna database khusus untuk aplikasi ini, juga bernama silapor, dengan kata sandinya sendiri. Terakhir, kita memberinya hak hanya atas database silapor. Kenapa tidak memakai root saja? Karena kalau suatu saat aplikasi kita dibobol, penyerang hanya mendapat satu database, bukan semuanya.

Sekarang buka berkas titik env. Berkas ini menyimpan pengaturan yang berbeda di setiap komputer, termasuk kata sandi. Cari baris yang berawalan DB. Pastikan DB_CONNECTION berisi mysql dan DB_DATABASE berisi silapor. Ganti DB_USERNAME dari root menjadi silapor, lalu isi DB_PASSWORD dengan kata sandi yang baru kita buat. Kalau kata sandimu mengandung tanda pagar atau spasi, apit dengan tanda kutip. Lalu lihat baris APP_KEY di bagian atas. Itu kunci rahasia untuk mengenkripsi sesi login, dan sudah diisi otomatis oleh penginstal.

Perhatikan dua hal. Berkas titik env tidak ikut ke GitHub, karena namanya tercantum di berkas titik gitignore. Yang ikut adalah titik env titik example, yaitu contoh tanpa isi rahasia. Jadi, kalau kamu mengambil proyek ini dari GitHub, salin dulu titik env titik example menjadi titik env, isi bagian database-nya, lalu jalankan php artisan key:generate.

Satu pengaturan lagi. Buka config garis miring app titik php, cari timezone, lalu ganti UTC menjadi Asia garis miring Jakarta. Kalau dibiarkan UTC, laporan yang masuk jam tujuh pagi akan tercatat jam dua belas malam, karena selisih tujuh jam.

Kita uji sambungannya dengan php artisan migrate. Artisan adalah alat perintah bawaan Laravel, dan kita akan sering memakainya. Perintah ini membuat tabel-tabel bawaan di database. Kalau muncul deretan tulisan DONE, sambungan ke MySQL berhasil. Kalau muncul Access denied, artinya nama pengguna atau kata sandi di titik env belum cocok.

Jalankan php artisan serve, lalu buka localhost titik dua delapan ribu di browser. Halaman selamat datang Laravel muncul. Server ini berjalan selama terminalnya terbuka. Untuk menghentikannya, tekan Control C.

Terakhir, kita simpan titik awal ini di Git. Ketik git init, git add titik, lalu git commit dengan pesan proyek Laravel baru. Mulai sekarang, setiap bab ditutup dengan satu commit. Alat sudah siap. Di bab berikutnya, kita belum menulis kode, karena kita perlu mengobrol dulu dengan orang yang akan memakai aplikasinya.
