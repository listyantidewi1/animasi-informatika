# SiAntre: Kebutuhan Versi 1
Klien: Pak Rahmat, Bengkel Maju Jaya

## User story
- Sebagai pelanggan, aku ingin melihat posisi antreanku di HP,
  supaya aku bisa menunggu di warung sebelah tanpa takut terlewat.
- Sebagai petugas loket, aku ingin memanggil pelanggan berikutnya
  dengan satu tombol, supaya aku tidak perlu berteriak.
- Sebagai pemilik, aku ingin melihat jam tersibuk,
  supaya aku bisa mengatur jadwal mekanik.

## Kriteria terima
- Posisi di HP berubah < 3 detik setelah petugas memanggil,
  tanpa me-refresh halaman.

## Status tiket
waiting -> called -> serving -> done
called -> skipped -> called
waiting -> cancelled
