**Deskripsi:**
```
Proyek: Aplikasi Berbasis Data Terbuka — bagian 1 dari 2: Kebutuhan dan Desain Alur Data. Narasi suara plus teks besar di layar; ada versi tanpa suara di video terpisah.

Proyek penutup kelas XI semester dua: menggabungkan alur pengembangan (F11.1) dan data terbuka (F11.5) menjadi satu program Python kecil. Bersama Kiko kita bangun aplikasi Cek Bulan Kemah untuk OSIS: kebutuhan dari wawancara, desain alur data (baca file CSV, bersihkan, rangkum per bulan, beri rekomendasi), implementasi sebagai fungsi-fungsi kecil dengan list dan dictionary, pengujian dengan test case untuk sel kosong, kode 999, dan baris kembar, lalu rilis versi 1.0 dengan README dan pemeliharaan versi 1.1. Ditutup panduan proyek kelompok. Semua data fiktif. Gaya diagram Fase F. Empat cek pemahaman; perakit program dan penguji fungsi di halaman latihan.

Setelah menonton, murid bisa:
• merencanakan proyek program kecil mengikuti alur pengembangan
• membaca file CSV dan menyimpan datanya dalam list dan dictionary
• memecah program menjadi fungsi: baca, bersihkan, rangkum, rekomendasikan
• menguji fungsi dengan test case dan merilis versi dengan README
