Untuk guru: cara memakai episode ini (20 JP)

Tujuan (F11.10, elemen BK, AP, dan AD, Fase F): murid mengembangkan program kecil mengikuti alur pengembangan (F11.1) untuk mengolah data terbuka (F11.5): kebutuhan, desain alur data, implementasi sebagai fungsi kecil (list, dictionary, modul csv), pengujian dengan test case, rilis dengan README, dan pemeliharaan.

  • Pertemuan 1–2 (4 JP), kebutuhan dan lingkup: permainan kartu data berpindah tangan. Tonton Bagian 1. Kelompok memilih set data terbuka daerahnya, mewawancarai "pengguna" (guru, OSIS, petugas perpustakaan), dan menulis kebutuhan wajib dan tambahan untuk versi 1.0.
  • Pertemuan 3–4 (4 JP), desain: gambar alur data (fungsi dan data yang diserahkan), pilih struktur data (list, dictionary), tulis pseudocode tiap fungsi. Latihan 1 (perakit program).
  • Pertemuan 5–7 (6 JP), implementasi dan uji: tonton Bagian 2. Satu fungsi demi satu: tulis, jalankan, cetak hasilnya. Latihan 2 (penguji fungsi); tiap kelompok menulis minimal enam test case dengan hasil harapan sebelum menjalankan.
  • Pertemuan 8–9 (4 JP), rilis: Latihan 3 (pemeriksa README). README, catatan perubahan, dan uji silang: kelompok lain menjalankan program hanya dengan membaca README.
  • Pertemuan 10 (2 JP), presentasi: lima menit per kelompok dengan demo langsung, tabel test case, dan rencana versi berikutnya.

Penilaian: dokumen kebutuhan, gambar alur data, kode berfungsi kecil yang terbaca, tabel test case, README, catatan perubahan, presentasi. Hasil kuis tersimpan hanya di perangkat murid.
