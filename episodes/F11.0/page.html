Untuk guru: cara memakai episode ini (10 JP)

Tujuan (F11.0, unit jembatan): memetakan kemampuan awal murid kelas XI (mapel pilihan), mengulang pseudocode dan logika benar-salah, lalu menjalankan dan mengubah program pertama dalam Python. Elemen prasyarat, Fase F. Lingkungan Python apa pun boleh: IDLE, editor daring di lab, atau aplikasi di HP.

  • Pertemuan 1 (2 JP), diagnostik: permainan berdiri-duduk dan robot kata. Tonton Bagian 1. Kuis diagnostik; guru merekap peta kelas (pseudocode, logika, Python).
  • Pertemuan 2 (2 JP), penguatan: kelompok sesuai peta: pseudocode (D9.1/E.7 dan pelacak), logika (tabel kebenaran dari kalimat sehari-hari), yang aman menulis pseudocode untuk teman.
  • Pertemuan 3 (2 JP), program pertama: tonton Bagian 2. Setiap murid mengetik dan menjalankan program halo-nama, lalu program hitung lulus. Pelacak Python mini di halaman ini sebelum menjalankan di komputer.
  • Pertemuan 4 (2 JP), error dan ubah: tiap murid sengaja membuat tiga error berbeda (SyntaxError, NameError, IndentationError), membaca pesannya, memperbaiki. Lalu tiga perubahan program dengan tebakan tertulis sebelum dijalankan.
  • Pertemuan 5 (2 JP), gerbang: kuis diagnostik ulang untuk bekal yang tadinya merah; tiap murid menyerahkan satu program kecil buatan sendiri (input, if, for) beserta hasil pelacakannya. Pseudocode dan logika harus lulus sebelum F11.2.

Catatan: skor 2 dari 3 per bekal dianggap aman. Hasil kuis tersimpan hanya di perangkat murid.
