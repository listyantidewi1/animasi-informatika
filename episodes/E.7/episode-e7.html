Untuk guru: cara memakai episode ini (6 JP)

Tujuan pembelajaran (E.7): murid menuliskan rancangan program sederhana dalam pseudocode yang memakai variabel, tipe data, array, dan prosedur/fungsi. Elemen BK, Fase E. Notasi: DEKLARASI/ALGORITMA, tipe integer/float/string/boolean, DIV dan MOD, array berindeks mulai 0, FUNGSI … → tipe dengan KEMBALIKAN, PROSEDUR tanpa nilai balik.

  • Pertemuan 1 (2 JP), tipe dan ekspresi: permainan kartu masuk kotak tipe. Tonton Bagian 1. Latihan 2 Perbaiki tipe. Murid menulis program konversi (suhu, mata uang) dengan deklarasi lengkap, lalu melacaknya dengan dua input.
  • Pertemuan 2 (2 JP), array dari nol dan fungsi: permainan resep teh (fungsi dengan parameter). Tonton Bagian 2. Latihan 1 Pelacak. Murid menulis fungsi kecil (luas, genap_ganjil dengan MOD, nilai terbesar dalam array) dan melacak pemanggilannya dengan frame lokal di kertas.
  • Pertemuan 3 (2 JP), program utuh: Latihan 3 Susun program. Tugas: satu program utuh per murid (deklarasi, array, satu fungsi, program utama) untuk persoalan kecil, ditukar dan dilacak oleh teman. Asesmen: program dan hasil pelacakan teman. Penutup: intipan Python sebagai motivasi kelas XI.

Target minimum: deklarasi tipe benar, array berindeks 0 tanpa keluar batas, satu fungsi berparameter yang dipanggil dengan benar. Pengayaan: fungsi yang memanggil fungsi lain; prosedur dengan parameter array.
