# Judul dan deskripsi YouTube — E.5 Struktur Data Standar

## E.5a

**Judul** (68 karakter):
Informatika Kelas 10 | Struktur Data Standar (1/2): Array dan Record

**Deskripsi:**
```
Struktur Data Standar — bagian 1 dari 2: Array dan Record. Narasi suara plus teks besar di layar; ada versi tanpa suara di video terpisah.

Program menyimpan data dalam struktur data yang punya aturan main sendiri. Bersama Kiko kita kenali empat struktur data standar: array (deretan kotak sejenis bernomor, akses langsung lewat indeks, telusuri dengan ULANGI), record (satu benda dengan banyak keterangan: siswa.nama, siswa.nilai; array berisi record menjadi tabel), stack (push, pop, peek; terakhir masuk pertama keluar: tombol undo dan kembali), dan queue (enqueue, dequeue; pertama masuk pertama keluar: queue cetak dan pesan). Ditutup dengan tabel memilih struktur data yang tepat. Gaya diagram Fase E. Empat cek pemahaman; simulator push/pop dan enqueue/dequeue di halaman latihan.

Setelah menonton, murid bisa:
• menjelaskan array: indeks, akses langsung, penelusuran dengan perulangan, dan batas indeks
• menjelaskan record dan array berisi record sebagai tabel
• menjalankan operasi stack (push, pop, peek) dan queue (enqueue, dequeue) serta meramalkan isinya
• memilih struktur data yang sesuai untuk sebuah persoalan dan memberi alasannya

Video ini cocok untuk yang mencari: struktur data array record stack queue kelas 10; stack dan queue penjelasan sederhana; array dan record informatika sma; push pop enqueue dequeue simulasi.
```
