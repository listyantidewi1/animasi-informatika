**Deskripsi:**
```
Paket Berlapis di Internet — video simulasi konsep untuk Informatika kelas 11.

Simulasi konsep: satu permintaan halaman web dibungkus lapis demi lapis (segmen TCP dengan port, paket IP dengan alamat dan TTL, bingkai jaringan), melompat dari router ke router, lalu dibuka lapis demi lapis di server. Ada empat variasi: halaman web lawan pesan chat, tujuan yang lebih jauh, TTL yang habis di tengah jalan, dan segmen yang hilang lalu dikirim ulang oleh TCP. Setiap variasi diawali jeda untuk menebak. Semua alamat rekaan.

Setelah menonton, murid bisa:
• menjelaskan isi header TCP, IP, dan bingkai pada satu paket
• membedakan peran alamat IP dan nomor port
• menghitung TTL setelah paket melewati beberapa router
• menjelaskan cara TCP mengetahui dan mengirim ulang segmen yang hilang

Video ini cocok untuk yang mencari: enkapsulasi tcp ip animasi; cara kerja paket data di internet kelas 11; apa itu TTL pada paket IP; perbedaan alamat IP dan port; simulasi pengiriman paket jaringan.
```
