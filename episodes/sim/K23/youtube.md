Binary Search Tree dan Hash Map — video simulasi konsep untuk Informatika kelas 12.

Simulasi konsep: kita menyisipkan tujuh angka ke binary search tree dalam dua urutan berbeda dan melihat bentuk pohonnya, termasuk pohon miring dari data yang sudah urut. Lalu kita mencari angka sambil menghitung langkahnya, dan terakhir menyimpan nama ke hash map dengan fungsi hash banyak huruf dibagi lima, sampai terjadi tabrakan (collision). Setiap variasi dimulai dengan tebakanmu.

Setelah menonton, murid bisa:
• menyisipkan angka ke binary search tree: kecil ke kiri, besar ke kanan
• menjelaskan mengapa urutan sisip yang terurut membuat pohon miring
• menghitung langkah pencarian di pohon seimbang dan pohon miring
• menentukan nomor laci dengan fungsi hash dan menangani tabrakan

Video ini cocok untuk yang mencari: cara kerja binary search tree; contoh soal binary search tree; apa itu hash map dan collision; fungsi hash sederhana modulo; informatika kelas 12 struktur data.
