Membersihkan Data Terbuka dari File CSV

Setelah menonton, kamu bisa membuka file CSV di lembar kerja, membersihkan sel kosong, kode 999, baris kembar, dan format yang berbeda, lalu mencatat setiap langkahnya. Simulasi ini melengkapi episode F11.5, F11.10, F12.3. Hentikan videonya di setiap jeda "Coba sekarang" untuk mencoba sendiri.

Yang kamu pelajari

  • mengimpor file CSV dengan pemisah koma atau titik koma
  • menemukan sel kosong dengan filter dan memutuskan tindakannya
  • mengganti kode 999 dan -1 dengan Cari dan ganti, lalu menghapus baris kembar
  • mencatat setiap langkah pembersihan di lembar catatan
