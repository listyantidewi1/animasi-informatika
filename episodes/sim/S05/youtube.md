Membersihkan Data Terbuka dari File CSV — video simulasi praktik untuk Informatika kelas 11–12.

Simulasi praktik langkah demi langkah di aplikasi lembar kerja: membaca metadata data terbuka, mengimpor file CSV dengan pemisah titik koma, menemukan sel kosong dengan filter lalu memutuskan dihapus atau dibiarkan, mengganti kode 999 dan -1 (tidak ada data) dengan Cari dan ganti, menghapus baris kembar, menyeragamkan format, dan mencatat setiap langkah di lembar catatan. Ada jeda untuk mencoba sendiri dan tiga cek pemahaman.

Setelah menonton, murid bisa:
• mengimpor file CSV dengan pemisah koma atau titik koma
• menemukan sel kosong dengan filter dan memutuskan tindakannya
• mengganti kode 999 dan -1 dengan Cari dan ganti, lalu menghapus baris kembar
• mencatat setiap langkah pembersihan di lembar catatan

Video ini cocok untuk yang mencari: cara membuka file csv di spreadsheet; cara membersihkan data di lembar kerja; cara menghapus data duplikat di spreadsheet; data cleaning excel untuk pemula; cara import csv titik koma.
