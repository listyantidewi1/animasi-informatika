Folder dan File di Laptop dan HP

Setelah menonton, kamu bisa membuat folder, memberi nama file yang jelas, menyimpan di tempat yang benar, dan menemukan file itu lagi di laptop maupun HP. Simulasi ini melengkapi episode D7.0, D7.8. Hentikan videonya di setiap jeda "Coba sekarang" untuk mencoba sendiri.
