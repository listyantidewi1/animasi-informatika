Saat Data Membesar — video simulasi konsep untuk Informatika kelas 11.

Simulasi konsep: kita menghitung jumlah perbandingan cari linear lawan cari biner, lalu bubble sort lawan fungsi sorted() bawaan Python, untuk 10, 100, 1.000, dan 1.000.000 data. Setiap variasi dimulai dengan tebakanmu, lalu dijalankan dan dibandingkan. Di akhir, keempat algoritma digambar dalam satu grafik pertumbuhan.

Setelah menonton, murid bisa:
• menghitung perbandingan pada kasus terburuk, bukan mengukur detik
• membandingkan cari linear (n) dengan cari biner (log n) saat data membesar
• menghitung perbandingan bubble sort dengan rumus n(n−1)/2
• membaca grafik pertumbuhan n, log n, n log n, dan n²

Video ini cocok untuk yang mencari: perbedaan linear search dan binary search; kompleksitas algoritma untuk pemula; berapa langkah binary search sejuta data; bubble sort berapa perbandingan; informatika kelas 11 efisiensi algoritma.
