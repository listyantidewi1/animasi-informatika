Berbagi Halaman lewat Server Web Kecil Python — video simulasi praktik untuk Informatika kelas 11.

Simulasi praktik langkah demi langkah: menyiapkan folder berisi index.html, menyalakan server web kecil dengan python -m http.server 8000 di Terminal, membuka halamannya lewat localhost, lalu dari laptop teman di Wi-Fi yang sama lewat alamat IP. Membaca log GET 200 dan 404, mematikan server dengan Ctrl+C, aturan keamanan, dan tiga kesalahan umum: port sudah dipakai, firewall memblokir, dan salah folder.

Setelah menonton, murid bisa:
• menyalakan server web kecil Python dari folder yang tepat
• membuka halaman lewat localhost dan alamat IP laptop
• membaca log permintaan GET dengan kode 200 dan 404
• berbagi dengan aman dan mematikan server dengan Ctrl+C
