Halaman Web Pertama dengan HTML — video simulasi praktik untuk Informatika kelas 12.

Simulasi praktik langkah demi langkah: kelompok Sinta membuat halaman web pertama untuk aplikasi proyek mereka, Setor Sampah. Kita menulis kerangka HTML di editor kode, lalu tag h1, p, img dengan alt text, dan a; menyimpannya sebagai index.html; membukanya di browser; lalu mengubah, menyimpan, dan memuat ulang. Ada jeda untuk mencoba sendiri, tiga kesalahan yang sering terjadi (tag tidak ditutup, nama file gambar salah, lupa alt), dan tiga cek pemahaman. Semua nama dan situs di video ini rekaan.

Setelah menonton, murid bisa:
• menulis kerangka halaman HTML di editor teks
• memakai tag h1, p, img dengan alt text, dan a
• menyimpan file sebagai index.html dan membukanya di browser
• memperbaiki tag yang tidak ditutup, nama file gambar yang salah, dan alt yang terlupa

Video ini cocok untuk yang mencari: cara membuat website dengan html untuk pemula; belajar html dasar; cara membuat halaman web di notepad; cara menampilkan gambar di html; html kelas 12 informatika.
