Mulai belajar Python tanpa ribet dengan Jupyter Notebook.

1. Pasang: pip install notebook (atau pakai Google Colab di browser, tanpa memasang apa pun)

3. Di browser, klik New > Notebook, lalu ketik kode di sel, mis. print("Halo, dunia!")
4. Tekan Shift + Enter untuk menjalankan sel
