# H02 · Metadata YouTube Short

**Judul:** Cara Pasang dan Atur Git Pertama Kali #shorts

**Deskripsi:**

```
Mengatur Git sekali saja sebelum commit pertama: pasang, isi nama dan email, atur branch main, lalu cek.

1. Pasang Git. Windows: unduh dari https://git-scm.com lalu klik Next sampai selesai. Mac/Linux: pakai pengelola paket.
   Cek: git --version
2. git config --global user.name "Nama Kamu"
   git config --global user.email "email@kamu.id" (sama dengan email akun GitHub)
3. git config --global init.defaultBranch main
4. Cek hasilnya: git config --global --list

Lanjut membuat commit pertamamu:
Git dari Nol: Commit Pertamamu
```
