# H08 · Metadata YouTube Short

**Judul:** Cara Membuka Aplikasi Lokal di HP #shorts

**Deskripsi:**

```
Aplikasimu jalan di laptop tapi tidak bisa dibuka di HP? Buka lewat Wi-Fi yang sama.

1. Server harus mendengarkan di 0.0.0.0, bukan hanya localhost (contoh: app.listen(3000, "0.0.0.0")).
2. Cari IP laptop. Linux: hostname -I. Windows: ipconfig, lihat IPv4 Address.
3. Sambungkan HP ke Wi-Fi yang sama, buka browser, ketik http://IP-laptop:port (mis. http://192.168.1.10:3000).
4. Belum terbuka? Di Windows, klik Allow access di peringatan firewall dan pilih jaringan Private.

Lanjut membuat aplikasi yang dirancang untuk HP:
Vibe Coding yang Benar: Membuat Aplikasi Patungan Sampai Jadi (Claude Code)
https://youtu.be/IgF3FA2gkOo

Terminal di video ini adalah rekaman sungguhan; tampilan HP digambar ulang. Suara narasi dibuat dengan text-to-speech.

Subscribe: https://www.youtube.com/@iTeachSWE

#webdevelopment #nodejs #belajarcoding #tutorialcoding #programmer
```
