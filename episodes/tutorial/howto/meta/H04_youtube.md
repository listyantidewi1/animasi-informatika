# H04 · Metadata YouTube Short

**Judul:** Cara Membereskan Merge Conflict di Git #shorts

**Deskripsi:**

```
Muncul CONFLICT saat merge? Begini cara membaca tanda konflik dan membereskannya.

1. git merge nama-branch -> Git berhenti dan menulis CONFLICT.
2. Buka berkasnya. Antara <<<<<<< dan ======= ada versi kita; antara ======= dan >>>>>>> ada versi branch lain.
3. Pilih isi yang benar, lalu hapus ketiga baris penanda.
4. git add nama-berkas, lalu git commit. Cek: git log --oneline --graph
```
