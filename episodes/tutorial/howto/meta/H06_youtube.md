# H06 · Metadata YouTube Short

**Judul:** Cara Membuat Proyek Laravel Pertamamu #shorts

**Deskripsi:**

```
Membuat proyek Laravel baru dan membuka halaman sambutannya di browser.

Windows/Mac: cara termudah, pasang Laravel Herd (https://herd.laravel.com). PHP dan Composer sudah ikut terpasang.
1. Cek: php -v dan composer -V
2. composer create-project laravel/laravel nama-proyek (tunggu sampai muncul DONE)
3. cd nama-proyek, lalu php artisan serve
4. Buka http://127.0.0.1:8000 di browser

Lanjut membangun aplikasi Laravel lengkap sampai online:
Membangun Aplikasi Laravel dari Nol: Lapor Sarana Sekolah
https://youtu.be/R71WByPI0Zo

Terminal di video ini adalah rekaman sungguhan. Suara narasi dibuat dengan text-to-speech.

Subscribe: https://www.youtube.com/@iTeachSWE

#laravel #php #belajarcoding #webdevelopment #programmer
```
