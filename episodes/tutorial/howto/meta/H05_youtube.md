# H05 · Metadata YouTube Short

**Judul:** Cara Pasang Node.js dan Cek Versinya #shorts

**Deskripsi:**

```
Memasang Node.js versi LTS lalu memastikan node dan npm siap dipakai.

Windows/Mac: buka https://nodejs.org, unduh versi LTS, lalu klik Next sampai selesai.
Linux (pakai nvm):
1. curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
2. source ~/.bashrc
3. nvm install --lts
4. Cek: node -v dan npm -v

Lanjut membangun aplikasi lengkap dengan Node.js:
Membangun Aplikasi dari Nol: Sistem Antrean Bengkel
https://youtu.be/lcO4Av0bkKY

Terminal di video ini adalah rekaman sungguhan. Suara narasi dibuat dengan text-to-speech.

Subscribe: https://www.youtube.com/@iTeachSWE

#nodejs #javascript #belajarcoding #webdevelopment #programmer
```
