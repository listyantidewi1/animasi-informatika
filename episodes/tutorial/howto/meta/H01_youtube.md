# H01 · Metadata YouTube Short

**Judul:** Cara Pasang Claude Code dalam 4 Langkah #shorts

**Deskripsi:**

```
Cara memasang Claude Code dari nol: pasang, cek versi, jalankan di folder proyek, lalu login.

1. Mac/Linux: curl -fsSL https://claude.ai/install.sh | bash
   Windows (PowerShell): irm https://claude.ai/install.ps1 | iex
2. Kalau muncul catatan PATH, jalankan perintah yang disarankan, lalu cek: claude --version
3. Buat folder proyek, masuk ke folder itu, lalu ketik: claude
4. Pilih tema, lalu login dengan akun Claude berlangganan (paket Pro ke atas) lewat browser.

Tonton video lengkapnya, membuat aplikasi Patungan sampai jadi dengan Claude Code:
Vibe Coding yang Benar: Membuat Aplikasi Patungan Sampai Jadi (Claude Code)
https://youtu.be/IgF3FA2gkOo

Terminal di video ini adalah rekaman sungguhan. Suara narasi dibuat dengan text-to-speech.

Subscribe: https://www.youtube.com/@iTeachSWE

#claudecode #vibecoding #tutorialcoding #belajarcoding #programmer
```

**Komentar tersemat:**

```
Muncul error "claude: command not found"? Itu tanda PATH belum diatur. Jalankan perintah echo ... >> ~/.bashrc yang muncul setelah pemasangan, lalu buka ulang terminal. Video lengkapnya: https://youtu.be/IgF3FA2gkOo
```
