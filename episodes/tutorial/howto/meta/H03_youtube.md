# H03 · Metadata YouTube Short

**Judul:** Cara Push Proyek ke GitHub Pertama Kali #shorts

**Deskripsi:**

```
Mengirim proyek dari laptop ke GitHub untuk pertama kali dalam 4 langkah.

1. Di GitHub: New repository, beri nama, jangan centang "Add a README file", lalu Create repository.
2. Di folder proyek: git init, git add ., git commit -m "pesan singkat"
3. git remote add origin https://github.com/username/nama-repo.git
4. git push -u origin main
   Username: username GitHub. Password: pakai token (Settings > Developer settings > Personal access tokens), bukan password akun.

Lanjut bekerja bersama tim:
Remote dan Pull Request

```
