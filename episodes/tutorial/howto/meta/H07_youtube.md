# H07 · Metadata YouTube Short

**Judul:** Cara Mengisi File .env dengan Benar #shorts

**Deskripsi:**

```
Aplikasi gagal terhubung ke database? Cek cara mengisi berkas .env.

1. Salin contoh: cp .env.example .env (Windows: copy .env.example .env). Jangan ubah .env.example.
2. Isi DB_PASSWORD sesuai pengaturan database di komputermu.
3. Aturan: tidak ada spasi di sekitar tanda =, nilai yang mengandung spasi diberi tanda kutip.
4. Pastikan .env tertulis di .gitignore. Cek dengan git status: .env tidak boleh muncul.

Lihat .env dipakai di aplikasi sungguhan:
Membangun Aplikasi dari Nol: Sistem Antrean Bengkel
https://youtu.be/lcO4Av0bkKY

Terminal di video ini adalah rekaman sungguhan. Suara narasi dibuat dengan text-to-speech.

Subscribe: https://www.youtube.com/@iTeachSWE

#env #nodejs #laravel #belajarcoding #programmer
```

**Komentar tersemat:**

```
Sudah terlanjur push .env ke GitHub? Hapus dari repo dengan git rm --cached .env, tambahkan ke .gitignore, lalu ganti semua password dan kunci di dalamnya karena sudah sempat terbuka. Video lengkapnya: https://youtu.be/lcO4Av0bkKY
```
