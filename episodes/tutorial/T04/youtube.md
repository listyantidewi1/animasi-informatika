## Video utama (4:47)

**Judul:** Bikin Website Profil Diri dalam 10 Menit (HTML dan CSS untuk Pemula)

**Deskripsi:**

Bikin website profil dirimu sendiri dari nol dengan HTML dan CSS. Kamu belajar tag pembuka dan penutup, elemen bersarang, judul, paragraf, daftar, gambar, dan link, lalu memberi warna, jarak, dan bentuk kartu dengan CSS. Setiap konsep dijelaskan dengan animasi: tag sebagai label, kotak di dalam kotak, rumah kerangka yang dicat, dan lapisan padding, border, serta margin. Cukup memakai editor teks dan browser.

Kode lengkap:
<!DOCTYPE html>
<html>
<head>
    <title>Profil Raka</title>
    <style>
        body {
            font-family: sans-serif;
            background-color: #e0f2f1;
        }
        h1 {
            color: teal;
        }
        .kartu {
            background: white;
            padding: 24px;
            border-radius: 16px;
            max-width: 400px;
            margin: 40px auto;
        }
        img {
            border-radius: 50%;
        }
    </style>
</head>
<body>
    <div class="kartu">
        <h1>Halo, aku Raka</h1>
        <p>Aku kelas 8 dan suka menggambar.</p>
        <h2>Hobiku</h2>
        <ul>
            <li>Menggambar</li>
            <li>Bulu tangkis</li>
            <li>Membaca komik</li>
        </ul>
        <img src="raka.png" width="150">
        <a href="https://id.wikipedia.org">Tempat aku belajar</a>
    </div>
</body>
</html>
