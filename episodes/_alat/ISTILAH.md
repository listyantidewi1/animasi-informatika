# Daftar istilah informatika (disepakati 3 November 2026)

Aturan: pakai istilah asli dunia informatika (umumnya bahasa Inggris). Pada penyebutan pertama dalam satu episode boleh ditambah arti Indonesia dalam kurung atau dengan "atau": "array (deretan data bernomor)", "Stack, atau tumpukan, …". Sesudahnya pakai istilah aslinya saja. Jangan memakai terjemahan paksa yang jarang dipakai orang (larik, bulat sebagai nama tipe, galat, kueri, peramban, surel). Frasa terjemahan yang janggal (mis. "pseudocode longgar") diganti penjelasan langsung.

| Pakai | Jangan pakai | Catatan |
|---|---|---|
| array | larik | |
| integer, float, string, boolean | bulat, pecahan, teks (sebagai nama tipe) | "bilangan bulat", "teks" boleh sebagai penjelasan arti |
| record, field | rekaman (struktur data) | "rekaman" tetap untuk rekaman suara/video |
| stack, queue | tumpukan, antrean (struktur data) | kelas 7: contoh nyata dulu (antrean kantin, tumpukan piring), lalu "di komputer disebut queue/stack"; antrean nyata tetap "antrean" |
| error | galat | nama error Python tetap: SyntaxError, TypeError |
| file | berkas | |
| download, upload | unduh, unggah (teknis) | "unggah/unggahan" untuk posting media sosial boleh, sebut "upload" sekali |
| link | tautan | termasuk lapisan link TCP/IP |
| query | kueri | |
| browser | peramban | |
| email | surel | |
| screenshot | tangkapan layar | |
| password manager | manajer kata sandi | "kata sandi" tetap (judul unit CP D7.3) |
| hardware, software | perangkat keras, perangkat lunak | |
| input, output | masukan, keluaran (komputer) | "masukan" dalam arti umpan balik tetap |
| linear search, binary search | pencarian linear/biner | "pencarian dan pengurutan" sebagai nama topik boleh |
| base case, recursive case, call stack, frame | kasus dasar, bingkai | |
| test case, edge case | — | boleh berdampingan dengan "kasus uji", "kasus batas" |
| trace table | — | boleh berdampingan dengan "tabel pelacakan" |
| cloud | penyimpanan awan | |

Tetap Indonesia (bentuk resmi CP atau sudah umum): kata sandi, lembar kerja, pengolah kata, percabangan, perulangan, fungsi, variabel, penyimpanan, penyedia internet, klien, daring, folder, aplikasi, ikon, klik.

Notasi pseudocode tetap memakai kata kunci Indonesia (BACA, TULIS, JIKA … MAKA, UNTUK, SELAMA, FUNGSI, KEMBALIKAN), dengan nama tipe asli: `nilai : array[0..4] dari integer`.
