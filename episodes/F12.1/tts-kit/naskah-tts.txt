intro1	Halo, kelas dua belas! Aku Kiko. Aplikasi peta, folder di laptop, dan daftar teman di media sosial menyimpan data yang saling terhubung. Setelah menonton, kamu bisa memilih dan memakai struktur data yang tepat untuk programmu.
intro2	Di kelas sepuluh kita mengenal array, record, stack, dan queue. Sekarang empat struktur baru: linked list, hash map, tree, dan graph. Kita mulai dengan memakai yang sudah disediakan Python, lalu mengintip cara membuatnya sendiri.
intro3	Episode ini melanjutkan E.5 tentang struktur data standar dan F12.0 tentang list, dictionary, dan fungsi. Kalau stack dan queue terasa asing, tonton lagi E.5, ya.
play1	Main dulu. Lima teman duduk acak di kelas. Tiap orang hanya memegang kartu bertuliskan nama teman berikutnya. Untuk menemukan orang keempat, kamu harus mulai dari orang pertama dan mengikuti kartunya satu per satu. Itulah linked list.
play2	Lalu loker kelas bernomor nol sampai empat. Aturannya: banyak huruf nama dibagi lima, sisanya menjadi nomor loker. Dito, empat huruf: loker empat. Mencari tas Dito tidak perlu membuka semua loker. Itulah ide hash map.
s1a	Abstract data type, atau tipe data abstrak, menjelaskan apa yang bisa dilakukan, bukan bagaimana data disimpan. Stack: push dan pop. Queue: masuk di belakang, keluar dari depan. Cara menyimpannya urusan pembuat library.
s1b	List Python bisa menjadi stack: append untuk push, pop mengambil yang teratas. Untuk queue, pakai deque dari modul collections: append di belakang, popleft dari depan. Mengapa bukan list? Mengambil dari depan list menggeser semua isinya.
q1	Cek pemahaman. Stack kosong: append tiga, append lima, pop, append tujuh. Isi stack dari bawah ke atas: tiga dan tujuh; lima dan tujuh; atau tiga, lima, tujuh? Pikirkan dulu.
q1a	Jawabannya: tiga dan tujuh. pop mengambil lima yang paling atas, lalu tujuh ditaruh di atas tiga.
s2a	Linked list terdiri dari node. Tiap node menyimpan data dan penunjuk ke node berikutnya. Node pertama disebut head, dan node terakhir menunjuk ke None. Untuk membaca isinya, mulai dari head, lalu ikuti penunjuknya satu per satu.
s2b	Kelebihannya: sisip di tengah cukup mengubah dua penunjuk. Kekurangannya: mengambil isi keseribu harus berjalan seribu langkah dari head. List Python sebaliknya: indeks mana pun langsung terambil, tetapi sisip di depan menggeser semuanya.
q2	Cek pemahaman. Program riwayat pesan sering menyisipkan pesan baru di depan, tetapi jarang mengambil pesan berdasarkan nomor. Mana yang lebih cocok: linked list, atau list Python biasa? Pikirkan dulu.
q2a	Jawabannya: linked list. Menyisipkan di depan cukup membuat node baru yang menunjuk ke head lama. Di list biasa, semua isi harus digeser.
s3a	Bagian dua. Hash map menyimpan pasangan kunci dan nilai. Fungsi hash mengubah kunci menjadi nomor laci. Dictionary Python adalah hash map. Saat kamu meminta stok teh, Python menghitung nomor laci untuk teh dan langsung membukanya.
s3b	Dua kunci bisa mendapat laci yang sama. Dito dan Kiko sama-sama empat huruf: tabrakan, atau collision. Keduanya disimpan berdampingan di laci itu, lalu dicocokkan kuncinya. Selama lacinya cukup banyak, mencari tetap cepat.
q3	Cek pemahaman. Kamu ingin menghitung berapa kali tiap kata muncul dalam satu cerpen. Struktur mana yang paling cocok: stack, dictionary dengan kata sebagai kunci, atau linked list? Pikirkan dulu.
q3a	Jawabannya: dictionary. Tiap kata menjadi kunci, nilainya jumlah kemunculan. Bertemu kata yang sama, tinggal tambah satu di lacinya.
s4a	Tree, atau pohon, menyimpan data bertingkat: folder di laptop, silsilah keluarga, struktur organisasi OSIS. Node paling atas disebut root. Node di bawah suatu node disebut child, dan node tanpa child disebut leaf.
s4b	Aturan binary search tree: yang lebih kecil ke kiri, yang lebih besar ke kanan. Sisipkan lima puluh, tiga puluh, tujuh puluh, dua puluh, empat puluh, enam puluh, delapan puluh. Mencari enam puluh: lima puluh, kanan, kiri. Tiga langkah.
q4	Cek pemahaman. Empat puluh lima disisipkan ke pohon tadi. Di kanan empat puluh, di kiri tiga puluh, atau di kanan tujuh puluh? Pikirkan dulu.
q4a	Jawabannya: di kanan empat puluh. Empat puluh lima lebih kecil dari lima puluh, jadi ke kiri; lebih besar dari tiga puluh, ke kanan; lebih besar dari empat puluh, ke kanan lagi.
s5a	Graph menyimpan hubungan: node dan garis penghubung yang disebut edge. Contohnya halte angkot dan jalurnya, atau siapa berteman dengan siapa. Di Python cukup dictionary berisi list: tiap halte menyimpan daftar tetangganya.
s5b	Pilih sesuai kebutuhan. Batalkan langkah terakhir: stack. Layani sesuai urutan datang: queue. Sering sisip di tengah: linked list. Cari lewat kunci: dictionary. Data terurut yang cepat dicari: binary search tree. Hubungan dan rute: graph.
s6a	Sekarang giliranmu. Di halaman latihan: binary search tree interaktif, sisipkan dan cari nilai sambil melihat jalurnya; pemilih struktur data untuk enam kasus; dan pelacak stack dan queue di Python.
s6b	Lalu di komputer: pakai deque untuk antrean kantin dan dictionary untuk menghitung kata. Tantangan: buat linked list sendiri dengan dictionary sebagai node, lalu tulis fungsi yang mencetak semua isinya.
recap	Tiga hal untuk diingat. Satu: abstract data type menjelaskan operasinya; Python menyediakan stack, queue, dan hash map. Dua: linked list cepat disisipi, dictionary cepat dicari. Tiga: tree untuk data bertingkat, graph untuk hubungan.
