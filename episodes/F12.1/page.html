Untuk guru: cara memakai episode ini (24 JP)

Tujuan (F12.1, elemen BK dan AP, Fase F): murid merancang dan mengimplementasikan program yang memakai struktur data kompleks dan abstrak (linked list, tree, graph, hash map) dengan library yang tersedia. Target minimum: memakai list sebagai stack, deque sebagai queue, dan dictionary sebagai hash map, serta membaca gambar tree dan graph. Target lanjutan: membuat linked list dan binary search tree sendiri (node berupa dictionary).

  • Pertemuan 1 (2 JP): permainan rantai kartu nama dan loker. Tonton Bagian 1 sampai segmen library. Latihan 3 (pelacak stack dan queue).
  • Pertemuan 2–3 (4 JP), stack dan queue: fitur undo sederhana dengan list; antrean kantin dengan deque. Bandingkan waktu list.pop(0) dan deque.popleft() untuk 100.000 data dengan modul time.
  • Pertemuan 4–5 (4 JP), linked list: gambar di kertas dulu, lalu kode: tambah di depan, cetak semua isi, sisip setelah node tertentu. Lanjutan: hapus node.
  • Pertemuan 6–7 (4 JP), hash map: tonton segmen Hash map. Hitung kata dalam cerpen dengan dictionary; simulasi fungsi hash dan collision dengan kartu dan kotak.
  • Pertemuan 8–9 (4 JP), tree: Latihan 1 (binary search tree interaktif), menggambar BST dari urutan sisip berbeda (urutan terurut menghasilkan pohon miring). Lanjutan: fungsi sisip dan cari BST.
  • Pertemuan 10–11 (4 JP), graph: peta sekolah atau jalur angkot sebagai dictionary berisi list: daftar tetangga, cek dua tempat terhubung langsung. Latihan 2 (pemilih struktur data).
  • Pertemuan 12 (2 JP), asesmen: kasus aplikasi perpustakaan kelas: murid memilih struktur untuk tiap fitur (antrean pinjam, cari judul, riwayat, rak bertingkat) dan menuliskan alasannya.

Catatan: rumus hash "banyak huruf % 5" di video hanya contoh; Python memakai fungsi hash yang jauh lebih rumit. Semua nama dan data dalam episode ini fiktif.
