```
Struktur Data Kompleks dan Abstrak — bagian 1 dari 2: ADT, Library, dan Linked List. Narasi suara plus teks besar di layar; ada versi tanpa suara di video terpisah.

Struktur data kompleks dan abstrak untuk kelas XII. Kiko mulai dari ide abstract data type (yang penting operasinya, bukan cara menyimpannya), lalu memakai yang sudah disediakan Python: list sebagai stack, deque sebagai queue, dan dictionary sebagai hash map. Setelah itu linked list (node, penunjuk, head, sisip tanpa menggeser), fungsi hash dan collision, tree dengan root, child, dan leaf, binary search tree (kecil ke kiri, besar ke kanan, cari dalam beberapa langkah), serta graph sebagai dictionary berisi list untuk jalur angkot fiktif. Ditutup panduan memilih struktur sesuai kebutuhan. Gaya diagram Fase F. Empat cek pemahaman; binary search tree interaktif di halaman latihan.

Setelah menonton, murid bisa:
• menjelaskan abstract data type dan memakai stack, queue, serta hash map dari library Python
• menggambar dan menelusuri linked list, serta menyebut kelebihan dan kekurangannya
• menyisipkan dan mencari nilai di binary search tree
• menyimpan graph sebagai dictionary berisi list
• memilih struktur data yang tepat untuk suatu kebutuhan
