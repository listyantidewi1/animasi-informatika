# Cek Bulan Kemah v1.0
Program ini membaca data hujan harian (CSV), melewati
data rusak, lalu menyebut bulan dengan hari hujan paling sedikit.
## Cara menjalankan
1. Unggah `hujan_sukamaju.csv` lewat ikon folder.
2. Pilih Runtime → Jalankan semua.
## Contoh
- Masukan: `2025-08-02,12` (tanggal, mm; 999 = tidak terukur)
- Keluaran: `Bulan terbaik untuk kemah: 08`

Sumber data: Portal Data Terbuka (fiktif)
